How LDI works

Lost Demand Intelligence — a search analytics engine built for e-commerce

Real-time intent classification

Every "no results" event is classified before the user presses Enter. The engine separates typos from genuine B2B queries — queries that signal missing inventory, not broken UX.

Gold Signal detection

When a user searches for a product that doesn't exist in the catalog, then buys an alternative anyway — that's a Gold Signal. Confirmed purchase intent on an untracked product. The highest-value training signal in the system.

Domain generalization

The same engine runs on automotive parts and consumer electronics — only the domain knowledge layer (brands, categories, feature extractor) gets rebuilt per vertical, which is real work, not a zero-effort transfer. 91/100 on automotive (the original domain), 167/183 on electronics (the second one) — both measured 23.09.2026, full results.

Structured output for fine-tuning

Every query is stored as a labeled record: intent confidence, semantic validity flag, reward score, Gold/Positive/Negative classification. Ready to export as JSONL fine-tuning data.

Weekly intelligence report

Not raw logs. A structured PDF report: top missing products by search volume and estimated revenue impact, with prioritized restocking recommendations. Decision-ready output.

Stack

Python · Flask · SQLite · WebSocket · custom semantic validation pipeline · reward scoring engine · JSONL fine-tuning export · real-time debug dashboard. Built and maintained by one engineer.

Prior work — Skankran

Before LDI: built Skankran from scratch with no prior programming experience — a water quality analysis platform integrated with the Google Gemini API and grounded in WHO/EPA documentation.First platform of its kind in Poland. That project is what led to this one.
